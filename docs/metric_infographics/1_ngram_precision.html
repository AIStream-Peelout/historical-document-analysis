Scoring Hebrew manuscript transcription · the order-independent n-gram precision

Is it on the page?

A transcription model can fail by reading badly, or by writing fluent text that was never there. Character error rate cannot tell those apart on a Cairo Genizah fragment, where the "right order" is often an editor's guess. So we ask one narrower question: of everything the model wrote, how much actually occurs somewhere on this page?

4

Slide a five-letter window over each

Every run of five consecutive letters is a window. The reference's 21 windows go into a lookup set; the output's 30 windows are checked against it one by one. Order never enters: a window matches wherever it sits on the page.

Read the pattern: the single misread letter (כ for ב) breaks exactly the five windows that contain it. The nine invented letters of שלום וברכה break all nine windows they touch. A window is either on the page or it is not.

Score = share of the output's windows found on the page

0.5316 of 30 windows

Precision, not recall: the metric asks whether what was written is real, not whether everything on the page was read. Coverage is measured separately by aligned recall. In the resubmission each reference window can be claimed at most as many times as it occurs, so an output that repeats one genuine phrase a hundred times no longer earns credit a hundred times.

6

Sort the output into a behaviour class

Checked in this order; the first rule that fires wins. CER is reported only for outputs that reach the last row, so the score works as the admission filter for error-rate metrics.

Abstainedfewer than 25 letters asserted, or a refusal phrase
Loop collapseone repeated 12-letter span covers more than 45 % of the text
Hallucinatedscore below 0.10: what was written is not this page
Substantiveeverything else. Our example, at 0.53, lands here and goes on to CER.

A fragment is Tier A when an order-blind line recogniser (Kraken) and at least one vision-language model both score 0.25 or more against the reference: two independent readers agreeing that the editor transcribed the right layer in the right order, which is what makes an error rate meaningful there.

Why this and not CER

Three things the window score does that an error rate cannot

0credit for invented text, wherever it is placed

A fluent paragraph that is not on the page contains no reference windows. It scores the same whether it is inserted at the top, the bottom, or woven through real lines.

15 of 33reading-order "failures" that were Kraken reading correctly

On pages with marginalia, over-writing or a palimpsest under-text, the editor's linearisation is a choice. A system that reads the transcribed lines in a different order keeps its score; alignment-based metrics punish it.

0.005median score of a real transcription against the wrong page

Scoring every good output against all 130 other fragments gives an empirical null. Under 1 % of those wrong-page pairs reach 0.10, and 0.1 % reach 0.25: the two cutoffs sit at the null's 99th and 99.9th percentiles.

What it does not see

An off-page detector, and only that

Text copied from elsewhere on the same page. A model that patches an illegible passage with a formula it already read three lines up keeps, or even raises, its score. Only order-aware metrics (aligned F1, CER) notice.
Canonical interpolation. A liturgical or biblical fragment completed from the model's memory of the standard text shares most of its windows with the page. The judge and the scholar have to catch this one.
A layer the editor did not transcribe. Marginalia read correctly but absent from the reference score as hallucination. The metric is invariant to reading order, not to which layer was chosen.
Near-miss reads are penalised, by design. One wrong letter costs five windows, so the score rewards getting letters exactly right. The trade-off is why n = 5: three-letter windows match almost any Hebrew text (wrong-page median 0.22), eight-letter windows break on every small confusion.
