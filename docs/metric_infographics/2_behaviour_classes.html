Behaviour classification · the paper's primary result

How did it fail?

Three outputs can all score a character error rate near or above 1.0 and mean completely different things: one declined, one jammed on a single word, one wrote fluent Hebrew from somewhere else. Ranking those numbers ranks the shape of the failure, not reading ability. So every output is sorted into a behaviour class before it is scored, and only the last class goes on to an error rate.

Gate 1: did it assert anything?

An output is an abstention if it asserts fewer than 25 letters, or if a refusal phrase appears in its first 400 characters — cannot transcribe, unable to read, sorry and their neighbours. Only A stops here: the damage marker [?] is apparatus, not ink, so it asserts nothing at all.

A → abstainednothing asserted; no attempt to read was made, and no error rate is computed
B, C, Dletters asserted, no refusal phrase — they go on to gate 2

The letter count is script-agnostic: Hebrew and Arabic blocks both count as asserted ink. An output written entirely in Arabic script is therefore never an abstention. It claimed to have read something, and it is judged on that claim by the gates below.

classify · ABSTAIN_MIN_CHARS = 25 · _REFUSAL_RE over raw[:400]

Gate 2: is it one phrase on repeat?

Take every run of twelve consecutive letters, find the single commonest one, and multiply its count by twelve: that is how many letters of the output that one span accounts for. Divide by the output's length. Above 0.45 the output is a loop collapse. The test needs at least 36 letters, so a short answer cannot trip it.

5

Only substantive attempts get an error rate

D is the single output of the four that was reading this page, and its character error rate — 0.41 — means what an error rate is supposed to mean. Score all four with CER and you get numbers that are perfectly well defined and rank the wrong thing:

A · abstainedCER 1.00 — the cost of deleting the page. Nothing was read, nothing was wrong.
B · loop collapseCER 2.69 — worst of the four, because it wrote too much. It wrote one real word.
C · hallucinatedCER about 1.0 — indistinguishable from the abstention, and a different failure entirely
D · substantiveCER 0.41 — the only one of the four where the number is about reading

Averaged, that column says the refusal beat the loop by 1.69 and tied the hallucination. It is a ranking of failure shapes wearing the clothes of an accuracy metric. Hence the order: classify, then score the class that can be scored.

Why the class comes before the number

Three readings an error rate gets exactly backwards

2.69 vs 1.00CER of a loop versus CER of a refusal

Both are failures on the same page, and the numbers say the refusal is the better system. Neither read anything. A metric that rewards writing less is not measuring reading.

50 %of the benchmark GPT-5.6 Sol declines to attempt

Average its CER over the attempts only and it looks competitive, on the half of the corpus it chose. Refusals stay in the table at full n, so coverage and accuracy are read together.

68 %of pages Claude Sonnet 5 hallucinates

Fluent, on-topic, wrong page. This is the failure the paper's title is about, and on its own CER cannot see it: invented Hebrew and misread Hebrew cost roughly the same characters.

What it does not see

Four classes, three thresholds, and the gaps between them

The loop gate needs one exact 12-letter span. A long output that recycles several real phrases with variation between them never concentrates on a single window, and passes as substantive. Fourteen HebVL-1.7 outputs ran from three to twenty-four times the reference length; they were caught only once count clipping was added to the five-gram score.
The hallucination gate inherits the five-gram score's blind spots. Text copied from elsewhere on the same page, and canonical text completed from memory, both share windows with the reference and both pass. The gate detects off-page writing, not invention as such.
The thresholds are conventions. 25 letters, 0.45, 0.10: a sweep shows the Kraken systems and the frontier ordering are robust to them, and that HebVL-1.7's margin over Gemini Pro is not — it holds from a cutoff of 0.05 to 0.15 and fails at 0.20.
Mixed-script output is deliberately not abstention. Writing Arabic where the page is Hebrew is an assertion, not a decline, so it is never counted as caution. It falls through to the loop and hallucination gates and is judged there, like any other claim about the page.
